📋 📌 DESCRIPCIÓN DEL PROYECTO

Este proyecto implementa un Sistema de Gestión de Servicios para un Gimnasio utilizando Programación Orientada a Objetos en Python. Permite administrar diferentes tipos de membresías, clientes y operaciones del gimnasio Y usa un sistema CRUD completo para la gestión de membresías de un gimnasio. Implementa:

- **✅ Programación Orientada a Objetos** (5 clases requeridas del 1er parcial)
- **✅ Interfaz Gráfica con Qt/PySide6** diseñada con Qt Designer
- **✅ Conexión a SQL Server 2022** con operaciones CRUD completas
- **✅ Arquitectura en capas** (Dominio → Datos → Servicio → UI)
- **✅ Validaciones y mensajes de usuario**


### **📋 Del Documento del 2do Parcial:**
| Requisito | Estado | Evidencia |
|-----------|--------|-----------|
| Reutilización del 1er parcial | ✅ | 5 clases POO en `/dominio` |
| Base de datos SQL Server | ✅ | Conexión funcionando a `DESKTOP-OMLK3LH\SQLKERSEYLOOR` |
| UI con Qt Designer | ✅ | Archivo `.ui` en `/ui_qt` + código Python |
| Formulario con campos | ✅ | QLineEdit, QComboBox, QCheckBox implementados |
| Botones CRUD | ✅ | Guardar, Buscar, Actualizar, Eliminar, Limpiar |
| Mensajes de validación | ✅ | QMessageBox para éxito/error |
| CRUD completo | ✅ | Create, Read, Update, Delete implementados |
| Script de base de datos | ✅ | `db.sql` para creación de tablas |
| Estructura en capas | ✅ | Dominio, Datos, Servicio, UI separados |

### **📦 Del 1er Parcial (reutilizado):**
- ✅ **5 clases POO**: `ServicioGym`, `MembresiaPresencial`, `MembresiaVirtual`, `Cliente`, `GestorGym`
- ✅ **Encapsulamiento**: Atributos privados con `@property` y `@setter`
- ✅ **Herencia**: Superclase abstracta con 2 subclases
- ✅ **Polimorfismo**: Métodos comunes en listas de objetos
- ✅ **Buenas prácticas PEP8**: Código documentado y estructurado
